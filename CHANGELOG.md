## [0.9.0] - 2026-01-27

### Добавлено

- **Документация хостинга**: инструкции по развертыванию preview-окружения ([fba4706](https://github.com/quilin/dm/commit/fba47063))
- **Скрипт автоустановки**: автоматизация установки на сервере ([f55851f](https://github.com/quilin/dm/commit/f55851fd))
- **Защита паролем**: конфигурация nginx для базовой аутентификации preview-сервера ([c88772d](https://github.com/quilin/dm/commit/c88772d3))
- **OpenIddict**: полная интеграция OAuth 2.0 аутентификации
  - Token endpoint с password и refresh_token grant flows
  - Userinfo endpoint для получения claims пользователя
  - Dual-mode аутентификация (Bearer токены + legacy X-Dm-Auth-Token)
  - LegacyTokenAuthenticationHandler для обратной совместимости
- **Middleware для consumers**: Polly retry policies для Search и Notification consumers
- **Проверки безопасности**: environment checks для OpenIddict сертификатов

### Изменено

- **PBKDF2 итерации**: увеличено с 100,000 до 600,000 (стандарт OWASP 2025)
- **API URL**: исправлены пути к API в preview конфигурации
- **API response codes**: исправлены несоответствия HTTP статус-кодов в контроллерах
- **Структура документации**: разделение задач на TASKS.md, CURRENT.md, ROADMAP.md, BACKLOG.md

### Исправлено

- API endpoints теперь возвращают корректные HTTP статус-коды
- Исправлена обработка ошибок в background consumers
- Улучшена обработка сбоев RabbitMQ

### Безопасность

- Увеличено количество итераций PBKDF2 до 600,000
- Добавлена версионность хешей паролей для миграции
- Улучшена обработка сертификатов OpenIddict в production

## [0.8.0] - 2026-01-26

### Добавлено

- **Frontend страницы игровой системы**:
  - `/games` - список игр с фильтрами
  - `/game/:id` - страница игры
  - `/create-game` - создание новой игры
- **Discord OAuth интеграция**: социальная авторизация через Discord
- **Integration тесты**: 117 интеграционных тестов для API
- **BBCode редактор**: Tiptap-based редактор с поддержкой специальных тегов
  - Базовые теги: bold, italic, link, image, quote
  - Специальные: spoiler, nsfw, modblock, private, cut
- **Тестовые аккаунты**: эндпоинт `/dev/accounts` для создания тестовых пользователей

### Изменено

- Улучшена производительность загрузки списков игр
- Оптимизированы запросы к БД с использованием индексов

---

## [0.7.0] - 2026-01-25

### Добавлено

- **Rate Limiting**: защита API от злоупотреблений
- **CSRF защита**: токены для защиты от межсайтовой подделки запросов
- **Database backups**: автоматическое резервное копирование PostgreSQL
- **Performance индексы**: оптимизация запросов к Games, Topics, Comments
- **Facades для внешних сервисов**: абстракции для MinIO, MongoDB Atlas Search

### Изменено

- Централизация конфигурации внешних сервисов
- Улучшена обработка загрузки файлов

---

## [0.6.0] - 2026-01-24

### Добавлено

- **Nullable reference types**: включены во всем проекте
- **378 unit тестов**: покрытие бизнес-логики
- **ILogger**: структурированное логирование во всех сервисах
- **MongoDB diagnostics**: мониторинг производительности запросов

### Изменено

- Миграция на .NET 8
- Обновление всех зависимостей до актуальных версий
- Рефакторинг структуры репозитория

---

## [0.5.0] - 2025-12

### Добавлено

- **Vue 3 миграция**: полный переход frontend на Vue 3 + Composition API
- **TypeScript**: строгая типизация frontend кода
- **Pinia**: замена Vuex на Pinia stores
- **Vite**: замена Webpack на Vite для ускорения разработки

### Изменено

- Переписаны все компоненты на Composition API
- Улучшена типизация API запросов
- Оптимизирован bundle размер

### Удалено

- Vuex store (заменен на Pinia)
- Webpack конфигурация (заменена на Vite)
- Vue 2 legacy режим

## [0.2.0] - 2025-09

### Добавлено

- **Игровая система**:
  - Создание игр с настройкой схем атрибутов
  - Система персонажей с кастомными атрибутами
  - Игровые комнаты и посты

### Изменено

## [0.1.0] - 2025-08

### Добавлено

- **Аутентификация**:
  - Регистрация пользователей с email-подтверждением
  - Вход по логину/паролю
  - Восстановление пароля
  - Token-based аутентификация (X-Dm-Auth-Token)
  - PBKDF2 хеширование паролей
- **Форумная система**:
  - Форумы и подфорумы
  - Создание топиков
  - Комментарии с BBCode
  - Система модерации
- **Инфраструктура**:
  - PostgreSQL для основных данных
  - MongoDB для вспомогательных данных
  - Docker Compose конфигурация
  - Serilog для логирования
  - Jaeger для трассировки
- **Backend архитектура**:
  - Clean Architecture / Hexagonal Architecture
  - CQRS с MediatR
  - AutoMapper для маппинга DTO
  - FluentValidation для валидации
  - Autofac DI контейнер
- **Frontend**:
  - Vue 2 (на момент старта)
  - Vuex для state management
  - Axios для API запросов
  - SCSS для стилей
