## Платформенные роли (UserRole)

Глобальная иерархия ролей пользователя на платформе:

```
Admin (5)              Полный доступ
    │
SeniorModerator (4)    Баны, опросы, утверждение ревью, назначение менторов
    │
Moderator (3)          Редактирование/удаление чужого контента
    │
Mentor (2)             Премодерация игр/блогов новичков
    │
RegularUser (1)        Стандартный доступ
    │
Guest (0)              Только чтение публичного контента
```

**Правило:** `user.Role >= UserRole.Mentor` означает Mentor и все выше.

## Роли в модулях

### GameRole — Роль в игре

```
Master (6)      Создатель и ведущий (Game.AuthorId)
    │
Assistant (5)   Помощник мастера (GameAssistants table)
    │
Mentor (4)      Куратор игры новичка (Game.MentorId)
    │
Player (3)      Игрок с активным персонажем
    │
Applicant (2)   Заявка на рассмотрении
    │
Reader (1)      Подписчик (Subscriptions table)
    │
None (0)        Не участвует
```

### BlogRole — Роль в блоге

```
Owner (4)       Создатель блога (Blog.AuthorId)
    │
Assistant (3)   Помощник (BlogAssistants table)
    │
Mentor (2)      Куратор блога новичка (Blog.MentorId)
    │
Reader (1)      Подписчик (Subscriptions table)
    │
None (0)        Нет связи с блогом
```

## Права на форуме

### BoardAccessPolicy (битовая маска)

Форумные разделы используют битовую маску для контроля доступа:

```csharp
None            = 0       // Нет доступа
Administrator   = 1 << 0  // 1
SeniorModerator = 1 << 1  // 2
Moderator       = 1 << 2  // 4
Mentor          = 1 << 3  // 8
RegularUser     = 1 << 5  // 32
Guest           = 1 << 6  // 64
```

**Применение:**
- `Board.ViewPolicy` — кто может просматривать раздел
- `Board.CreateTopicPolicy` — кто может создавать темы

## Intention Pattern

Авторизация реализована через паттерн Intention — декларативная проверка прав:

```csharp
// Проверка намерения без контекста
_intentionManager.ThrowIfForbidden(GameIntention.Create);

// Проверка намерения с контекстом
_intentionManager.ThrowIfForbidden(BlogIntention.Edit, blog);
```

Каждый модуль определяет свои Intention'ы и Resolver'ы в папке `Authorization/`.

## Ограничения

### Для новичков (< 100 постов)

| Ограничение | Описание |
|-------------|----------|
| Премодерация игр | Игры требуют одобрения ментора |
| Премодерация блогов | Публикации требуют одобрения ментора |
| Ревью на пользователей | Запрещено |
| Ревью на игры | Запрещено |
| Ревью на посты | Только нейтральные |

### Временные лимиты

| Ограничение | Значение |
|-------------|----------|
| Редактирование ревью | 24 часа с создания |
| Кулдаун ревью постов | 3 дня на игру |
| Редактирование сообщений | 15 минут |
