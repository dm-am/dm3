# Политика имен пользователей (Login)

## Правила валидации

### Модель: запрещающий список

Username может содержать **любые символы, кроме запрещенных** (deny-list, не allow-list).
Разрешенное не перечисляется: латиница, кириллица и другие алфавиты, цифры, `_`, `-`, `.`,
пробел (с ограничениями) — все проходит, если символ не входит в список ниже.

### Запрещенные символы

| Символ | Причина |
|--------|---------|
| `<` `>` | XSS-инъекция |
| `"` | HTML-атрибуты, SQL |
| `'` | SQL, JS-инъекция |
| `` ` `` | JS template literals |
| `\` | Escape-последовательности |
| `/` | URL path separator |
| `?` | URL query string |
| `#` | URL fragment |
| `%` | URL encoding |
| `&` | URL parameters, HTML entities |
| `@` | Email confusion, mentions |
| `[` `]` | Markdown, JSON |
| `(` `)` | Markdown links |
| `{` `}` | Template syntax |
| `=` | URL parameters |
| `~` | Home directory, regex |
| `!` `$` `^` `*` `+` `|` `;` `:` | Shell/regex special chars |
| Control chars | Невидимые символы |
| Zero-width | Спуфинг имен |

### Правила пробелов

- Не в начале
- Не в конце
- Не подряд

### Правило содержания

- Хотя бы одна буква или цифра

Имя целиком из пунктуации адреса не имеет: имя пользователя это сегмент пути, а
точечные сегменты и браузер, и HTTP-клиент сворачивают до отправки запроса, так что
`/users/..` уходит на сервер как `/users/`.

### Правила длины

- Минимум: 2 символа
- Максимум: 20 символов

### Регистр (Case Sensitivity)

**Case-preserving, case-insensitive** — индустриальный стандарт (GitHub, Discord, Twitter):

| Аспект | Поведение |
|--------|-----------|
| Хранение | Сохраняет оригинальный регистр ("Adam Advena") |
| Отображение | Всегда оригинальный регистр |
| Все сравнения | **Case-insensitive** |

**Примеры:**
- Регистрация "Adam" → "adam" недоступен
- Логин: "adam" + пароль → войдет как "Adam"
- URL: `/users/adam` → профиль "Adam"
- API: фильтр по имени пользователя принимает "adam" → найдет игры мастера "Adam"

---

## URL-стратегия

Используется URL-кодирование:

```
Имя:  "Adam Advena"
URL:  /users/Adam%20Advena
```
