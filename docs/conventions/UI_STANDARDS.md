# Стандарты интерфейса

Правила вида и поведения интерфейса, общие для всех экранов сайта. Каждый раздел живет целиком в одной из частей, под тем же заголовком, по которому его цитируют код и документы: `DocumentReferencesShould` находит цитату в части, на которую ведет список.

- [Раскладка и навигация](UI_STANDARDS/layout.md): шкалы, ширина окна, колонки, шапка, сайдбар, ряды, титул вкладки
- [Контролы и ссылки](UI_STANDARDS/controls.md): фильтры, таблицы, списки, контролы, ссылки, пагинация, фокус, даты
- [Окна](UI_STANDARDS/dialogs.md)
- [Состояния и отклик](UI_STANDARDS/states.md): пустое, загрузка, плашки, недоступное, гость
- [Поверхности и содержимое](UI_STANDARDS/surfaces.md): поверхности, текст, картинки, выделение, анимация, тема
- [Экраны разделов](UI_STANDARDS/screens.md): правила отдельных экранов
