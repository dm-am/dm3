## Error pages

### Существующие картинки

| Код | Значение | Картинка | Связь с ошибкой | Есть? |
|-----|----------|----------|----------------|-------|
| 400 | Bad Request | Гоблин жалуется троллю на укусившего сквигга | Некорректный запрос = хаос | ✅ готово |
| 401 | Unauthorized | Дверь с тентаклями, заперта на засов | Нет авторизации = дверь заперта | ✅ готово  |
| 403 | Forbidden | Тролль преграждает путь приключенцам | Нет прав = тролль-охранник | ✅ готово  |
| 404 | Not Found | Пустой сундук с вылетающей мошкой | Страница не существует = пусто | ❌ нужна новая |
| 409 | Conflict | Гоблины дерутся | Конфликт версий = конфликт гоблинов | ❌ нужна новая |
| 410 | Gone | Пепелище, гоблин сдувает дым с огнемета | Удалено навсегда = сожжено | ❌ нужна новая |
| 500 | Server Error | Гоблин со взорвавшимся огнеметом | Серверная ошибка = огнемет сломался | ✅ готово |

### Файлы картинок

Место хранения: `src/assets/images/errors/`.
