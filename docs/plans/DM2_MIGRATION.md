### SQL-скрипты миграции тегов

```sql
-- 1. Переименования
UPDATE "Tags" SET "Title" = 'World of Darkness' WHERE "Title" = 'WoD';
UPDATE "Tags" SET "Title" = 'Dawn of Worlds' WHERE "Title" = 'DoW';
UPDATE "Tags" SET "Title" = 'Warhammer' WHERE "Title" = 'WarHammer';
UPDATE "Tags" SET "Title" = 'Фэнтези' WHERE "Title" = 'Фентези';
UPDATE "Tags" SET "Title" = 'Историческое' WHERE "Title" = 'Исторические';
UPDATE "Tags" SET "Title" = 'Ужасы' WHERE "Title" = 'Ужас';
UPDATE "Tags" SET "Title" = 'Обязателен мессенджер' WHERE "Title" = 'Skype';

-- 2. Миграция данных "Донабор" → RecruitmentCount
UPDATE "Games" SET "RecruitmentCount" = 2
WHERE "GameId" IN (
    SELECT gt."GameId" FROM "GameTags" gt
    JOIN "Tags" t ON gt."TagId" = t."TagId"
    WHERE t."Title" = 'Донабор'
);

-- 3. Удаление тега "Донабор"
DELETE FROM "GameTags" WHERE "TagId" = (SELECT "TagId" FROM "Tags" WHERE "Title" = 'Донабор');
DELETE FROM "Tags" WHERE "Title" = 'Донабор';

-- 4. Перемещение тегов в новые группы
-- Выполняется после создания новых TagGroup в DM3
-- (скрипт генерируется на основе маппинга TagId → новый TagGroupId)
```

## Игры-блоги

### Концепция

71 игра с тегом "Блог" мигрируется в модуль Blog.

### Маппинг сущностей

| Game (DM2) | Blog (DM3) |
|------------|------------|
| Game | Blog |
| Game.Title | Blog.Title |
| Game.Info | Blog.Description |

| Game.CreatedUtc | Blog.CreatedUtc |

| Post.GameText + Post.MetagameText | Publication.Text |
| GameAssistant | BlogAssistant |

### Игнорируемые данные

- **Characters** — в блогах нет персонажей, публикации от имени автора
- **Tags** — блоги не имеют тегов
- **DiceRolls** — не применимо

## Посты

### Переименование полей

| DM2 | DM3 | Описание |
|-----|-----|----------|
| `Text` | `Text` (Game Text) | Игровой текст поста |
| `Comment` | `Comment` (Metagame Text) | Метаигровой комментарий (OOC) |

### MasterMessage → Comment

В DM2 у постов есть поле `MasterMessage` — приватное сообщение мастеру.

В DM3 это поле удалено. При миграции содержимое добавляется в конец `Comment` (Metagame Text) с BBCode приватом:

```
[существующий Comment]

[private=master,assistant]
[содержимое MasterMessage]
[/private]
```

**Примечание:** Если `Comment` пустой, приват добавляется без переноса строки.

### Алгоритм

```
1. Найти игры с тегом "Блог"
2. Для каждой:
   a. Создать Blog (сохранить тот же ID)
   b. Мигрировать Room → Rubric
   c. Мигрировать Post → Publication (объединить тексты)
   d. Мигрировать Comment, Subscription, Assistant, Blacklist
   e. Пометить Game.IsRemoved = true
3. Удалить тег "Блог"
```

## Модули-блокноты

### Концепция

На DM2 "модули-блокноты" — игры с особыми настройками, используемые как личные заметки.

В DM3 конвертируются в **личные блокноты** (Personal Notepads).

### Критерии

Игра считается блокнотом если **ВСЕ** условия выполняются:
- Название содержит "Блокнот" (регистронезависимо)
- Статус "В оформлении"
- "По приглашениям"
- Нет активных игровых персонажей

### Маппинг

| DM2 (Game) | DM3 (Personal Notepad) |
|------------|------------------------|
| Game.Title | Notepad.Title (без "Блокнот") |
| Game.Info | Notepad.Description |
| Game.MasterId | Notepad.OwnerId |
| Room | NotepadCategory |
| Post | NotepadEntry |
