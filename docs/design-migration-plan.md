# План миграции дизайна: Сравнение старого и нового сайта

## 1. Анализ типографики

### Старый сайт (DM2)
```
Шрифты:
- PT Sans – заголовки, кнопки, описания
- Twemoji – эмодзи
- DM Iconic – иконки
- Системные шрифты (apple-system, BlinkMacSystemFont, Roboto) – fallback
```

### Текущий сайт
```
Шрифты:
- PT Sans – всё
- Iconic – иконки

Размеры (px):
- Base: 16px
- Title: 20px
- Secondary: 14px
- Tertiary: 12px
- Menu: 25px
```

### Оценка

**Шрифты идентичны** – PT Sans на обоих сайтах. Отлично!

**Что можно улучшить:**
- Добавить Twemoji для консистентного отображения эмодзи
- Добавить системные шрифты в fallback

## 4. Рекомендуемые изменения

### Приоритет 1: Цвета границ и фонов (высокий)

**Themes.sass** - привести к DM2:

```sass
// Границы - сделать темнее
$border: color-set(#ccc, #ccc, #ccc, #ccc, #a8a8a8)  // было #dfdfdf

// Вторичный текст - сделать светлее
$secondary-text: color-set(#999, #999, #999, #999, #adadad)  // было #8a8a8a

// Ссылки hover - сделать темнее
$active-text-hover: color-set(#3f78a8, #3f78a8, #3f78a8, #3f78a8, #ffc73f)  // было #5a9fd4

// Цитаты - убрать сиреневый оттенок
$quote-background: color-set(#e6e6e5, #e6e6e5, #e6e6e5, #e6e6e5, #38353c)  // было #e8e8f2
$quote-outline: color-set(#b0c4de, #b0c4de, #b0c4de, #b0c4de, #a790c1)  // было #c3c3d5

// Красный - сделать светлее (firebrick)
$negative-text: color-set(#b22222, #b22222, #b22222, #b22222, #ec6f5b)  // было #900
```

### Приоритет 2: Добавить недостающие цвета (средний)

**Themes.sass** - добавить:

```sass
// Дополнительные серые для статусов
$offline-text: color-set(#777, #777, #777, #777, #999)
$inactive-text: color-set(#808080, #808080, #808080, #808080, #888)

// Зелёные варианты
$new-item-text: color-set(#393, #393, #393, #393, #9fc)  // новые игры/блоги
$unread-link: color-set(#696, #696, #696, #696, #8b8)  // непрочитанные ЛС

// Фоны сообщений
$message-background: color-set(#f2f1f1, #f2f1f1, #f2f1f1, #f2f1f1, #2a2a2a)

// Фоны инпутов
$input-background: color-set(#f9f9f9, #f9f9f9, #f9f9f9, #f9f9f9, #222)
```

### Приоритет 3: Кнопки (низкий)

Текущий стиль кнопок (синий фон, белый текст) - это **модернизация**.
DM2 использовал серые кнопки (#EAEAEA фон, #444 текст).

**Решение:** Оставить текущий стиль - он современнее.
