# Глоссарий терминов

## 1. Platform

| Код | Русский | Описание |
|-----|---------|----------|
| Platform | Платформа | DM.am — сайт для текстовых ролевых игр |
| Module | Модуль | Игра или блог — основные контентные единицы платформы |
| Community | Сообщество | Совокупность пользователей платформы |

---

## 2. Users

### Учётная запись
| Код | Русский | Описание |
|-----|---------|----------|
| User | Пользователь | Зарегистрированный участник платформы |
| Account | Аккаунт | Учётная запись для входа в систему |
| Login | Имя пользователя | Уникальный идентификатор пользователя в сообществе. Виден всем. |
| Profile | Профиль | Публичная страница с информацией о пользователе |
| Session | Сессия | Активная авторизация пользователя |
| Token | Токен | Одноразовый код для активации аккаунта или сброса пароля |
| PendingRegistration | Ожидающая регистрация | Запись с email и паролем до выбора имени пользователя |

### Статусы пользователя
| Код | Русский | Описание |
|-----|---------|----------|
| Active | Активный | Пользователь, который был онлайн в течение последнего месяца |
| Newbie | Новичок | Пользователь с малым опытом на платформе (< 100 постов) |
| Honorary | Почётный | Особый статус за заслуги |

### Роли платформы (UserRole)
| Код | Русский | Описание |
|-----|---------|----------|
| Guest | Гость | Неавторизованный посетитель |
| RegularUser | Пользователь | Стандартный зарегистрированный пользователь |
| Mentor | Наставник | Опытный пользователь, помогающий новичкам |
| Moderator | Модератор | Следит за соблюдением правил |
| SeniorModerator | Старший модератор | Модератор с расширенными полномочиями |
| Admin | Администратор | Полный доступ ко всем функциям |

---

## 3. Games Modules

### Основные сущности
| Код | Русский | Описание |
|-----|---------|----------|
| Game | Игра | Текстовая ролевая игра на платформе |
| GameTagGroup | Группа игровых тегов | Категория тегов (Жанр, Система, Сеттинг) |
| GameTag | Игровой тег | Метка для классификации игр (D&D, Sci-Fi, Horror) |
| AttributeSchema | Схема атрибутов | Шаблон характеристик персонажей в игре |

### Статусы игры (GameStatus)
| Код | Русский | Описание |
|-----|---------|----------|
| Draft | Игра оформляется | Игра в процессе создания |
| Active | Идёт игра | Игра активна |
| Closed | Игра закрыта | Игра закрыта |

### Флаги для закрытых игр
| Флаг | Русский | Описание |
|------|---------|----------|
| IsFinished | Игра завершена | Игра доведена до завершения |
| IsFrozen | Игра заморожена | Игра временно приостановлена |

### Набор игроков (Recruitment)
| Поле | Русский | Описание |
|------|---------|----------|
| RecruitmentOpen | Идёт набор | Набор открыт для новых игроков |
| PlayerLimit | Лимит игроков | Количество мест для игроков (null = безлимит) |
| PlayerCount | Количество игроков | Текущее число игроков с персонажами в игре |

### Комнаты
| Код | Русский | Описание |
|-----|---------|----------|
| Room | Комната | Пространство внутри игры для контента |
| PostRoom | Игровая комната | Комната для игровых постов |
| ChatRoom | Чат-комната | Комната для мета-общения участников |
| RoomAccess | Доступ к комнате | Права участника на доступ к закрытой комнате |
| PostPendency | Ожидание поста | Метка о том, что от участника ждут пост в комнате |

### Контент
| Код | Русский | Описание |
|-----|---------|----------|
| Post | Пост | Игровой контент от участника в игровой комнате |
| GameText | Игровой текст | Часть поста с внутриигровым содержанием |
| MetagameText | Мета-текст | Часть поста с внеигровой информацией (OOC-текст, пояснения для мастера) |
| Message | Сообщение | Сообщение в чат-комнате игры |
| DiceField | Поле бросков | Область с совершёнными и планируемыми бросками кубиков |
| DiceRoll | Бросок кубика | Результат случайного броска в игре |

### Персонажи
| Код | Русский | Описание |
|-----|---------|----------|
| Character | Персонаж | Игровой персонаж, от лица которого пишутся посты |
| PC | Персонаж игрока | Персонаж, управляемый игроком (Player Character) |
| NPC | Персонаж мастера | Персонаж, управляемый мастером (Non-Player Character) |
| Attribute | Атрибут | Свойство персонажа (сила, здоровье, навыки, предметы) |

### Статусы персонажей (CharacterStatus)
| Код | Русский | Описание |
|-----|---------|----------|
| UnderReview | Заявка на рассмотрении | Персонаж ожидает одобрения мастера |
| Declined | Заявка отклонена | Персонаж отклонён |
| Active | В игре | Персонаж активен |
| Retired | Вне игры | Персонаж выведен из игры |

### Флаги для персонажей вне игры
| Флаг | Русский | Описание |
|------|---------|----------|
| IsDead | Персонаж мёртв | Персонаж умер в процессе игры |
| IsPlayerLeft | Игрок покинул игру | Игрок покинул игру самостоятельно |
| IsPlayerExiled | Игрок выведен из игры | Игрока вывели из игры |

### Обсуждение
| Код | Русский | Описание |
|-----|---------|----------|
| Discussion | Обсуждение | Список комментариев в обсуждении игры |
| Comment | Комментарий | Комментарий в обсуждении игры |
| Like | Лайк | Отметка «нравится» на комментарий в обсуждении игры |

### Участие в игре (GameParticipation)
| Код | Русский | Описание |
|-----|---------|----------|
| Owner | Мастер | Создатель и ведущий игры |
| Assistant | Ассистент | Помощник мастера, назначенный через приглашение |
| Mentor | Наставник | Помощник мастеру-новичку (только настройки, без постов и блокнота мастера) |
| Player | Игрок | Участник с активным персонажем |
| Reader | Читатель | Подписчик игры без персонажа |
| None | Нет | Не участвует в игре |

### Блокноты
| Код | Русский | Описание |
|-----|---------|----------|
| PlayerNotepad | Блокнот игрока | Личные заметки игрока в конкретной игре |
| MasterNotepad | Блокнот мастера | Общие заметки мастера и ассистентов (не видно игрокам и читателям) |

### Приглашения
| Код | Русский | Описание |
|-----|---------|----------|
| Invitation | Приглашение | Предложение стать читателем, игроком или ассистентом игры |

### Ограничения
| Код | Русский | Описание |
|-----|---------|----------|
| Blacklist | Чёрный список | Чёрный список пользователей в игре |

## 7. Reviews

## 10. Moderation

| Код | Русский | Описание |
|-----|---------|----------|
| Warning | Предупреждение | Взыскание пользователю за нарушение правил |
| Ban | Бан | Временная или постоянная блокировка пользователя |
| Ticket | Обращение | Жалоба или вопрос в службу поддержки |
| TicketResponse | Ответ на обращение | Текст модератора или пользователя в тикете |
| ProfileModNote | Модераторская заметка | Внутренняя заметка модераторов о пользователе |

### Типы банов (BanType)
| Код | Русский | Описание |
|-----|---------|----------|
| Partial | Демократический | Запрет на публичную коммуникацию, доступ к своим играм сохраняется |
| Full | Полный | Максимальное ограничение прав |

### Премодерация модулей (PremoderationStatus)
| Код | Русский | Описание |
|-----|---------|----------|
| Approved | Не требует проверки | Модуль не требует проверки |
| AwaitingApproval | Ожидает проверки | Модуль ожидает проверки |
| AwaitingEdits | Ожидает правок | Модуль ожидает правок от владельца |
