# Глоссарий терминов DM

Справочник ключевых терминов и понятий, используемых в проекте.

## 1. Уровни доступа

| Термин | Описание |
|--------|----------|
| **Гость** | Неавторизованный пользователь, может только просматривать публичный контент |
| **Неверифицированный пользователь** | Зарегистрированный без подтверждения email, ограничения как у гостя, но может открыть профиль |
| **Новый пользователь** | Менее 100 игровых постов, только оценка +0, игры/блоги в премодерации |
| **Рядовой пользователь** | Обычный пользователь с полным доступом |
| **Почетный гоблин** | Рядовой пользователь с почетным статусом за заслуги |
| **Гоблин-наставник (Наставник)** | Помогает новичкам, выпускает из премодерации |
| **Младший гоблин (Модератор)** | Выставляет баллы, видит жалобы |
| **Старший гоблин (Старший модератор)** | Выдает баны, видит IP/email, отменяет решения |
| **Тролль (Администратор)** | Высший уровень, решения окончательны |

## 2. Пользователь

| Термин | Описание |
|--------|----------|
| **Аккаунт** | Совокупность всех данных о пользователе |
| **Профиль пользователя** | Видимая часть: ник, рейтинг, игры, блоги |
| **Рейтинг** | Числовой показатель на основе оценок постов |
| **Наставничество** | Система помощи новичкам при регистрации |
| **Личная заметка** | Приватная заметка на чужом профиле |
| **Черный список пользователя** | Список заблокированных пользователей |
| **Загруженные файлы** | Аватары, изображения пользователя |
| **Отзыв о пользователе** | Отзыв после совместной игры |

## 3. Модерация

| Термин | Описание |
|--------|----------|
| **Предупреждение** | Модераторское предупреждение с баллами |
| **Бан** | Блокировка с типом, сроком и причиной |
| **Демократический бан** | Запрет на публичные тексты, доступ к своим играм сохраняется |
| **Полный бан** | Максимальное ограничение прав |
| **Модераторская заметка** | Общая заметка модераторов о пользователе |
| **Блок модерации** | Служебная информация на профиле |

## 4. Премодерация (PremoderationStatus)

| Термин | Код | Описание |
|--------|-----|----------|
| **Не требует премодерации** | Approved (0) | Модуль одобрен или не требует проверки |
| **Ожидает премодерации** | AwaitingApproval (1) | Модуль ожидает проверки наставника |
| **Ожидает правок** | AwaitingEdits (2) | Наставник запросил изменения |

**Примечание:** Премодерация применяется к играм новых мастеров (рейтинг < 100)

## 5. Модули

| Термин | Описание |
|--------|----------|
| **Модуль** | Игра или блог с собственными правами доступа |
| **Мастер** | Создатель и владелец модуля |
| **Ассистент** | Помощник мастера с теми же правами |
| **Наставник (в модуле)** | Помогает с ведением, может модерировать |
| **Читатель** | Подписан на модуль, читает без участия |
| **Обсуждение** | Комментарии к модулю |
| **Блокнот** | Личные заметки мастера |
| **Черный список модуля** | Запрет на комментирование |
| **Приглашения** | Список приглашений от мастера |

## 6. Статусы модуля (GameStatus)

| Термин | Код | Описание |
|--------|-----|----------|
| **Оформляется** | Draft (0) | В процессе создания |
| **Идет игра** | Active (1) | Модуль активен |
| **Закрыта** | Closed (2) | Модуль закрыт |

**Дополнительные флаги для Closed:**

| Флаг | Описание |
|------|----------|
| **IsFinished** | Игра успешно завершена |
| **IsFrozen** | Игра заморожена (временно приостановлена) |

**Примечание:** Статус Closed + IsFinished = "Игра завершена", Closed + IsFrozen = "Игра заморожена"

## 7. Игры

| Термин | Описание |
|--------|----------|
| **Игра** | Игровой модуль для ролевых игр |
| **Игрок** | Участник с активным персонажем |
| **Игровой тег** | Метка: жанр, система, стиль |
| **Нарративный сеттинг** | Игровой мир/вселенная (NarrativeSetting) |
| **Игра завершена** | Флаг IsFinished: сюжет успешно завершён |

### Набор игроков (GameRecruitment)

| Поле | Описание |
|------|----------|
| **IsOpen** | Набор открыт для новых игроков |
| **PlayerLimit** | Максимум игроков (null = безлимит) |
| **PlayerCount** | Текущее число активных игроков |
| **StartedUtc** | Когда набор был открыт |

**Примечание:** Набор автоматически закрывается при закрытии игры

## 8. Комнаты

| Термин | Описание |
|--------|----------|
| **Комната** | Локация внутри игры для постинга |
| **Активная комната** | В основном списке |
| **Архивная комната** | Скрыта под спойлером |
| **Права доступа в комнату** | Разрешения на чтение/запись |
| **Метка ожидания поста** | Индикатор ожидания поста |

## 9. Персонажи

| Термин | Описание |
|--------|----------|
| **Персонаж** | Карточка с именем, аватаром, атрибутами |
| **Игровой персонаж (PC)** | Управляется игроком |
| **Неигровой персонаж (NPC)** | Управляется мастером/ассистентом |
| **Схема атрибутов** | Шаблон характеристик для игры |
| **Атрибуты персонажа** | Характеристики согласно схеме |

## 10. Статусы персонажей (CharacterStatus)

| Термин | Код | Описание |
|--------|-----|----------|
| **Заявка на рассмотрении** | UnderReview (0) | Ожидает одобрения мастера |
| **Отклонен** | Declined (1) | Заявка отклонена, скрыт |
| **В игре** | Active (2) | Активен и участвует |
| **Вне игры** | Retired (3) | Выведен из игры |

**Дополнительные флаги для Retired:**

| Флаг | Описание |
|------|----------|
| **IsDead** | Персонаж мертв (погиб по сюжету) |
| **IsPlayerLeft** | Игрок покинул игру самостоятельно |
| **IsPlayerExiled** | Игрок выведен из игры мастером |

**Примечание:** Статус Retired + IsDead = "Персонаж мертв", Retired + IsPlayerLeft = "Игрок покинул игру"

## 11. Игровой процесс

| Термин | Описание |
|--------|----------|
| **Игровой пост (Пост)** | Текст в игровой комнате |
| **Игровой текст** | Текст от лица персонажа |
| **Метаигровой текст** | Пояснения игрока вне персонажа |
| **Поле бросков** | Результаты бросков кубиков |
| **Броски кубиков** | Механика XdY+Z |
| **Оценка поста** | +1, +0, -1 с текстом |
| **Плюс** | Положительная оценка, +рейтинг |
| **Равно** | Нейтральная, доступна новичкам |
| **Минус** | Отрицательная, -рейтинг |

## 12. Блоги

| Термин | Описание |
|--------|----------|
| **Блог** | Модуль для публикаций автора |
| **Рубрика** | Раздел блога по тегу |
| **Тег рубрики** | Кастомная метка внутри блога |
| **Права доступа к тегу** | Разрешения на закрытый тег |
| **Публикация** | Запись в блоге с заголовком и тегами |

## 13. Форум

| Термин | Описание |
|--------|----------|
| **Форум** | Публичное пространство для общения |
| **Раздел** | Тематический раздел форума |
| **Тема** | Тема на форуме с заголовком |

## 14. Общение

| Термин | Описание |
|--------|----------|
| **Глобальный чат** | Общая среда в реальном времени |
| **Личный кабинет** | Приватное пространство для переписок |
| **Переписка (Visavi)** | Приватная переписка между двумя пользователями |
| **Групповая переписка** | Переписка с несколькими участниками (Title обязателен) |
| **Сообщение** | В глобальном чате или переписке |
| **Комментарий** | Под темами, публикациями, в обсуждениях |
| **Лайк** | Отметка "нравится" |

### Переписки (Conversation)

| Поле | Описание |
|------|----------|
| **Visavi** | `true` = диалог между двумя, `false` = групповая |
| **Title** | Название (обязательно для групповых, null для visavi) |
| **Participants** | Список участников переписки |

## 15. Поддержка

| Термин | Описание |
|--------|----------|
| **Обращение** | Жалоба, техподдержка, предложение |
| **Ответ в обращении** | Ответ модерации или пользователя |

## 16. Служебное

| Термин | Описание |
|--------|----------|
| **Базовый блок** | Простейший текстовый блок |
| **Отзыв о сайте** | Отзыв о платформе |
| **Опрос** | Вопрос с вариантами для голосования |
| **Голос** | Выбор в опросе |
| **Статистика сайта** | Автоматическая статистика |
| **Уведомление** | Системное уведомление |
