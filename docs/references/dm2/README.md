# Опись функций DM2

DM2, нынешний сайт на l.dm.am, образец DM3: DM3 его визуальный и функциональный преемник. Здесь все, что на DM2 может сделать или увидеть пользователь, мастер, игрок, читатель, автор блога, Новичок, ассистент, наставник и модератор. У функции номер, статус и метки четырех ролей. Строки без номера отсылают в другой раздел. Номер вида 4.12 ищется по разделам ниже. Что из этого брать в DM3, решается отдельно.
