## Видение проекта

DM3 - современная платформа для настольных ролевых игр (RPG) с форумом и социальными функциями.

**Ключевые характеристики:**
- Микросервисная архитектура
- Event-driven коммуникация (RabbitMQ)
- OAuth 2.0 с OpenIddict
- Real-time уведомления (SignalR)
- Полнотекстовый поиск (MongoDB Atlas Search)
